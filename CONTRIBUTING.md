# Contributing to Awesome ASO

Thank you for your interest in contributing! This list is curated by [Appalize](https://www.appalize.com?utm_source=github&utm_medium=awesome-aso), and we welcome contributions from the community.

## Guidelines

### Adding a New Resource

1. Make sure the resource is relevant to ASO (App Store Optimization) or mobile app growth.
2. Check that the resource isn't already listed.
3. Fork this repository and create a new branch.
4. Add the resource in **alphabetical order** within its appropriate category.
5. Use the following format:

```markdown
- [Resource Name](https://example.com/) — Brief description of the resource.
```

6. Submit a Pull Request with a clear title and description.

### What We Accept

- ✅ Free and paid ASO tools
- ✅ High-quality guides and tutorials
- ✅ Research papers and data reports
- ✅ Case studies with real data
- ✅ Open-source tools for mobile marketing
- ✅ Relevant podcasts and video channels
- ✅ Active communities and forums

### What We Don't Accept

- ❌ Low-quality or spammy content
- ❌ Resources behind mandatory sign-up walls (free resources should be accessible)
- ❌ Duplicate submissions
- ❌ Self-promotional links without substantial value
- ❌ Outdated resources (pre-2023)

### Quality Standards

- The resource should provide genuine value to app developers and marketers.
- Blog posts should be in-depth (1000+ words) and well-structured.
- Tools should be actively maintained and functional.
- Courses should have positive reviews or be from reputable sources.

## Suggesting a New Category

If you think a new category should be added, please open an issue first to discuss it.

## Code of Conduct

Please be respectful and constructive in all interactions. We follow the [Contributor Covenant](https://www.contributor-covenant.org/) code of conduct.

## Reporting Issues

If you find a broken link or outdated resource, please open an issue or submit a PR to fix it.
